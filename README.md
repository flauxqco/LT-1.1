# CIRCULAR GARDEN
##### A code used to compute for the area, circumference, and square root of a Circular Garden--including the area rounded to the nearest whole number up and down.
# HOW TO RUN:
##### To run this code, all you have to do is to enter the area of the garden then wait for the output (results).
# INPUT NEEDED:
##### The only input needed for this code to run as needed is the area of the garden.
# SAMPLE OUTPUT:
### Input: 5
### Area of the garden: 78.54 square meters
### Circumference of the garden: 31.42 meters
### Square root of the area: 8.86
### Area rounded down: 78 square meters
### Area rounded up: 79 square meters
